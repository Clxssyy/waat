# WAAT: Warborne Above Ashes Tools

[WAAT](https://waat.vercel.app) is a platform that allows users to create, share, and view character builds for the game Warborne Above Ashes.

## Features

- Character Builder

  - Up to 3 drifters per character.
  - Support Station
  - Add build descriptions w/ formatting.
  - Provide feedback w/ comments or ratings.
  - Conflicting equipment / drifter notices.
  - Allocate available stat points.
  - Select weapon skills.
  - View tier / mastery differences.
  - Private (unlisted) builds.
  - Character role selection (DPS / Healer / Tank).
  - Clone builds you like for expansion.

- Build Directory

  - Search for characters by role, drifter, name, or creator.

- Character Ratings
- Profiles

  - View all builds from the user.
  - Private (unlisted) builds are only shown to the creator.

- Guides

  - Currently a WIP (there are no guides), but space for user / creator guides is there.

- News

  - Currently a WIP (there is no news), but plans are to pipe Discord announcements / game updates.
